# Notes on papers

One JSON file per paper, written by the app through `papers/app/server.py`.
Each note records the section it was made in, the text quoted from the summary,
and whether it is still open.

These are tracked on purpose: they are reading notes, and they are worth as much
as the summaries they annotate. They are also plain JSON, so they can be read
without the app.

Add notes by selecting text in a summary and typing in the Notes box at the
bottom of the page.
